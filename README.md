# 📚 Estudos C#

Repositório criado para armazenar meus estudos, exercícios e experimentos durante o aprendizado da linguagem **C#** e do ecossistema **.NET**.

## 🎯 Objetivo

Este projeto tem como objetivo praticar e consolidar conhecimentos de programação utilizando C#, explorando conceitos fundamentais da linguagem por meio de pequenos projetos e exercícios práticos.

## 🛠️ Tecnologias utilizadas

- [C#](https://learn.microsoft.com/pt-br/dotnet/csharp/)
- [.NET](https://dotnet.microsoft.com/)
- Visual Studio 
- Git e GitHub
